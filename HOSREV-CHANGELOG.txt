SCREENS (tabs)
  revDash     Dashboard + AI morning brief + decisions/quiet-night lists
  revCalendar 30-night rate grid: recommend / approve / override / lock
  revCompset  our rate vs comp set, 14-night matrix + median

  revForecast occupancy forecast + net room profit per night

        capped by max daily change and locked dates; 3 reasons per rec.

        - the daily Rezlynx export is wired into revImport

NEW FILE

                       Optional on-site location (geofence) check.

CHANGED
  app.js               HosPEOPLE > Payroll & Clock-in panel now has:
                         "Load QR clock-ins"  -> pulls live punches into the
                                                 existing rota-vs-clock compare
                         "Clock-in QR & PINs" -> publish roster, print wall
                                                 poster, view/print staff PINs,
                                                 set geofence ("set to here")
  firestore.rules      + clock_roster (public read, staff write)
                       + clock_punches (public create of core fields; staff read)
                       + hosrev_* collections (staff only)

DATA MODEL
  clock_roster/current { geo:{enabled,lat,lng,radius},
                         staff:[{name, code, pinHash}] }   (PINs hashed, never stored plain)
  clock_punches/<auto> { staffCode, name, date, time, ts, mins, type, lat, lng, source }

RECONCILIATION  No new logic — live punches feed the SAME engine that already
  compares rostered vs actual hours and flags Match / Hours differ / No clock-in /
  Not on rota / missing clock-out, costed at each person's hourly rate, weekly & monthly.

HARDWARE  None. Printed poster + staff phones. Hotel coords default to Brandon
  (CV8 3FW ~52.3736,-1.3869); use "Set to here" on site to pin it exactly.

SETUP  Deploy the files, publish Firestore rules, then open
  HosPEOPLE > Payroll & Clock-in > "Clock-in QR & PINs" > Save & publish.
  Print the poster for the wall and the PIN slips for staff.
  Firebase Auth: enable Anonymous sign-in (Build > Authentication > Sign-in method)
